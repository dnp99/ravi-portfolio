# Content Editing Rules

Ravi's editable portfolio content lives in this directory.

- Edit existing Markdown files when updating a film or portrait.
- Add a new Markdown file when adding a new entry.
- Use lowercase kebab-case filenames.
- Keep frontmatter valid and use the existing field names.
- Do not change React, CSS, Sanity, or deployment files for routine content edits.
- Do not add facts that Ravi did not provide.
